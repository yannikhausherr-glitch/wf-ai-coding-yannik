# Regeln für KI-Assistenten in diesem Projekt

Dies ist das Lernprojekt einer Einsteigerin /
eines Einsteigers.

- Nur HTML, CSS und Vanilla JavaScript.
- Code bleibt in index.html, style.css, script.js.
- Kleine Schritte: ein Feature pro Auftrag.
- Erkläre jede Änderung auf Deutsch, einfach.
- Frag nach, wenn etwas unklar ist.
- Nenne 1–2 Dinge, die ich selbst testen soll.

## Technik
- Keine Frameworks, keine Bibliotheken, kein Build-Schritt, keine npm-Pakete.
- Die Seite muss ohne Server laufen: lokal mit Live Preview und später auf GitHub Pages.
- Daten, die bleiben sollen, im Browser-Speicher (localStorage) ablegen – keine Datenbank.

## Arbeitsweise
- Lies vor grösseren Änderungen SPEC.md – dort stehen Idee, User Stories und Datenmodell.
- Ändere nur die Dateien, die für den Auftrag nötig sind. Keine ungefragten Umbauten.
- Wenn ein Auftrag gross ist: zuerst einen kurzen Plan vorschlagen und auf mein OK warten.
- PROMPTLOG.md schreibe ich selbst – diese Datei nicht verändern.

## Lernmodus
- Schreibe einfachen, gut lesbaren Code mit kurzen deutschen Kommentaren.
- Verwende sprechende deutsche Namen für Variablen und Funktionen (z. B. `punkte`, `zeigeFrage`).
- Lieber einfach und verständlich als kurz und clever.
- Wenn ich frage «Warum?», erkläre das Konzept – nicht nur die Lösung.

## Sicherheit
- Keine Personendaten, Passwörter oder Schlüssel in Code, Kommentaren oder Beispieldaten.
